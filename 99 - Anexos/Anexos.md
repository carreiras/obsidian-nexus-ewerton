# Anexos

Guarde aqui PDFs, imagens, áudios e outros arquivos usados nas notas. Use nomes descritivos e vincule cada anexo à nota correspondente.

A pasta está pronta para armazenamento manual. Para direcionar novos anexos automaticamente para cá, escolha `99 - Anexos` em Configurações → Arquivos e links → Local padrão para novos anexos.
