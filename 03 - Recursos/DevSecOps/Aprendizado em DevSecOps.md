# Aprendizado em DevSecOps

## Objetivo
Aprender sobre DevSecOps e a importância da segurança no ciclo de desenvolvimento de software. Aprender a utilizar o GitHub Actions como ferramenta de CI/CD para automatizar processos e implementar segurança desde as primeiras etapas do desenvolvimento, seguindo o SSDLC (Ciclo de Desenvolvimento de Software Seguro).

## Forma de estudar
Seguir o [[Guia de organização do conhecimento]] para análise, pesquisa, aprovação, criação e revisão das notas.

## Perguntas que orientam o estudo
- Como DevSecOps, CI/CD e SSDLC se relacionam?
- Como automatizar processos com GitHub Actions?
- Como incorporar e verificar segurança ao longo do desenvolvimento?
