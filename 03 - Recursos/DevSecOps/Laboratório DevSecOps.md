# Laboratório DevSecOps

Espaço para registrar experimentos e exemplos que ajudam a compreender os conceitos estudados.

## Experimentos
Registros do projeto pessoal `devsecops-with-github-actions`, documentados em 2026-10-07 a partir dos arquivos e do histórico Git local:

- [[Laboratório — GitHub Actions — jobs e eventos]] — dependências, push, cron e etapas simuladas.
- [[Laboratório — GitHub Actions — action composta Soma]] — inputs, script Python e correções comprovadas pelos commits.
- [[Laboratório — GitHub Actions — publicação de artefatos]] — geração e upload de arquivo e distinção entre artefato e evidência de teste.
- [[Laboratório — Docker — construção, publicação e execução de imagem]] — Dockerfile Python, saídas locais registradas, publicação com digest e chamada da imagem no Actions.

Os registros de GitHub Actions demonstram configurações e alterações; resultados remotos permanecem pendentes de confirmação por logs e artefatos. O laboratório Docker inclui saídas de execução local e publicação registradas pelo usuário. Não houve execução de containers ou workflows durante a documentação.

## Roteiro para cada registro
- Pergunta ou hipótese a verificar.
- Conceitos relacionados e referências utilizadas.
- Ambiente, versões e repositório, quando houver.
- Passos executados.
- Resultado esperado e resultado observado.
- Evidências, erros e soluções.
- Conclusões e limitações do experimento.

Criar uma nota própria quando necessário. Uma aplicação com entrega definida, como implementar um pipeline em um repositório, pode se tornar um projeto em [[01 - Projetos/Índice — Projetos|Projetos]], ligado às notas de conhecimento.
